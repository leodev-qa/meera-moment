# Almeera Marketing Activations

**Meera Moment** — in-store AI campaign booth for almeera.

Shoppers capture a selfie, pick a campaign look (National Day, S'hail, Qatar GP, FIFA U-17, and more), and walk out with a poster and a six-second reel.

## Stack

TanStack Start · Vite · Vercel

## Scripts

```bash
npm install
npm run dev
npm run build
```

Set `XAI_API_KEY` in the environment so Imagine can restyle portraits.
